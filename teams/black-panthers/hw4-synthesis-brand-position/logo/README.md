# Plandit logo files

The approved visual reference is `logo-matrix.jpeg`. The production exports in this folder rebuild
that selected direction with Manrope ExtraBold 800 and the Plandit emerald/black palette.

## Usage

- Use `mark.svg` when the standalone layered P sits on a light neutral background.
- Use `mark-on-dark.svg` on black.
- Use `mark-black.svg` and `mark-white.svg` for single-color reproduction.
- Use `lockup-light.svg` and `lockup-dark.svg` for horizontal headers.
- Use the stacked lockups where horizontal space is limited but the full name is required.
- Use `avatar.svg` for social profiles and `favicon.svg` as the scalable favicon source.
- PNG favicon and platform sizes are generated from `favicon.svg`.

Do not recreate the tonal depth with CSS or recolor individual layers. Follow the logo rules in
`../style_guide.md`.
