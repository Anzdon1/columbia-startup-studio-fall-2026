# Persona tests

Test run on 2026-10-11.

- `artifacts/` holds what the personas judged. A1 is the brand position draft v0 (interview evidence only). A2 and A3 are the text of the two style-round-3 landing pages. A4 is a control that overclaims ("hard cap", "never run out"). A5 is a control that talks only about play. A6 to A10 are positive controls: copy written to pass for Wren, Rowan, Marlow, Emery and Quinn in that order. A6 to A10 are hypothetical copy written for this test, not published, and some assume statements about the product that nobody has checked.
- `verdicts/<artifact>.md` holds every verdict on that artifact, one per persona and run, each as the shared verdict JSON from `../README.md` in a code block. Each was produced by a separate agent with a fresh context that read only its own persona file and the one artifact. (The loose JSON files are kept outside this folder.)
- A first run on 2026-10-11 was thrown away: the product facts in the persona files wrongly said a stop in the middle of a turn was proposed for every agent, when OpenCode's live token count can do it. Five personas then flagged a correct sentence on both style pages. The facts were fixed and every persona was run again. The thrown-away results are kept outside this folder.
- One run per persona per artifact is noisy: scores moved by about a point between runs. See `../NOTES — grounding gaps.md` for the repeat runs and what they show.
- **Round 2, later on 2026-10-11.** The persona product facts were rewritten from the runner's own README (what a visit is, a sealed workspace, fake money, the agent asks each visit, no approval step described), and every persona judged three versions of the brand position four times: v0 (`A1_round2.md`), v1 (`A11_round2.md`) and v1.1 (`A12.md`), 60 runs. A11 and A12 are blind copies with every mention of the personas removed. The first-round verdicts for A1 and A11 stay in `A1.md` and `A11.md`. A12 is v1.1 as tested; the file handed in is v1.2, which has small fixes made after the test and has not been re-judged.
